# Tournoi-Manager
🏆 Tournoi Manager

    Gestion de tournois de figurines (Warhammer, AoS, Kill Team, Bolt Action...) — 100% locale, gratuite et sans compte.

Capture d'écran
🎯 Pourquoi ce logiciel ?

La plupart des outils de gestion de tournois demandent un compte, une connexion,ou placent leurs fonctionnalités derrière un abonnement. Tournoi Manager fait lechoix inverse : un seul fichier HTML, ouvert dans votre navigateur, et toutfonctionne. Vos données ne quittent jamais votre machine.

Idéal pour :

    🏰 Les clubs sans Wi-Fi fiable en salle
    🎒 Les organisateurs qui veulent un outil simple, prêt en 2 minutes
    🔒 Ceux qui refusent de confier les listes de leurs joueurs à un serveur

✨ Fonctionnalités

    4 formats d'appariement : système suisse automatique, élimination directe(bracket avec tableau SVG), hybride suisse + élimination directe et composition manuelle des tables
    Moteur suisse avancé : évite les revanches, les miroirs de faction, gèreles allégeances, les blocages manuels, la compo et les notes libres
    Gestion complète des joueurs : import CSV, statuts (préinscrit, actif,absent, drop), blocages, bonus/malus
    Scoring personnalisable : barème V/N/D libre, points de scénario, scorelibre (Kill Count...), pénalités
    Classement avec départages (points de scénario, SOS) et exports CSV/PDF
    Statistiques : par faction, par joueur, courbes de progression
    Timer de ronde avec alertes sonores (30/20/10 min)
    Bibliothèque de scénarios réutilisable d'un tournoi à l'autre
    Systèmes de jeu multi-factions avec allégeances (Warhammer 40K, AoS, etc.)
    Résilience : sauvegarde automatique, historique d'annulation, snapshotsde restauration, export/import JSON
    🌙 Thème sombre & clair · 📱 Interface responsive

🚀 Installation

Aucune installation. Aucune dépendance.

    Téléchargez tournoi-manager.html depuis la dernière release
    Double-cliquez dessus → il s'ouvre dans votre navigateur
    Créez votre premier tournoi. C'est tout.

    💡 Fonctionne hors-ligne après ouverture. Compatible Chrome, Edge, Firefox.📌 Astuce : épingler le fichier à la barre des tâches ou créer un raccourci.

📖 Démarrage rapide

    Système de jeu (optionnel) : onglet 🎲 pour définir factions et allégeances
    Créez un tournoi : nom, rondes, barème, critères d'appariement
    Ajoutez les joueurs : manuellement, ou import CSV Pseudo;Faction;Compo
    Passez-les "Actif" (bouton de check-in en masse disponible)
    Lancez la ronde 1 et saisissez les résultats au fil de la journée
    Exportez le classement en CSV ou PDF pour l'afficher

Un guide complet est intégré dans l'application : onglet ℹ️ Informations(tutoriel, explication du système suisse, glossaire).
🔒 Confidentialité

    Aucune donnée envoyée sur Internet — pas de serveur, pas de compte, pas de tracking
    Tout est stocké dans le localStorage de votre navigateur
    Utilisez l'export JSON pour sauvegarder/partager vos tournois
